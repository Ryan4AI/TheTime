## 1. 产品是什么（给未来的自己/别人看）

**一句话**：AI 根据真实历史数据生成剧情，让玩家穿越到真实历史场景里活一辈子。

**核心循环**：

```
选最多 3 件随身物品 + 性别
  → 按历史人口统计概率随机生成「年份/城市/年龄/阶层/职业」
  → AI 写剧情 + 3 个选项；玩家选 / 自由输入
  → AI₂ 打分：更新 9 项属性、推进月份、增减物品、判定死亡
  → 死亡 → 留遗言 → AI 生成墓志铭 → 下一世
```

- **9 属性**：声望 / 财富 / 学识 / 颜值 / 医术 / 战功 / 文采 / 政绩 / 义行（0~10000）
- **目标爽点**：留名青史 → 进入历史名人榜 → 超越真实历史人物
- **设计文档**：`docs/product-design.md`（单一事实源，§10.4 = 版本状态总览）
- **决策记录**：`docs/DECISIONS.md`（D001~D096+，改设计前必读，已定案不重开）

**状态流转基准**：`docs/state-flow.md`（谁改什么字段、AI 增量协议、死亡三判据）—— 改代码前必读。

## 3. 技术架构（3 分钟理解）

```
微信小游戏（minigame/，Canvas 2D，无框架）
  ├─ scenes/entry.js      入口
  ├─ scenes/selection.js  选随身之物
  ├─ scenes/intro.js      穿越动画
  ├─ scenes/identity.js   身份卡（宣纸 + 雷达图）
  ├─ scenes/game.js       主游戏页（叙事流 / 选项 / 物品栏 / 雷达 / DBG）
  ├─ scenes/death.js      死亡与墓志铭
  └─ scenes/leaderboard.js榜单浮窗
        │  云函数调用（wx.cloud.callFunction）
        ▼
云函数 ai_narrate_worker（两阶段：ai1 叙事 → ai2 打分）
        │  https.request → https://api.deepseek.com  (model: deepseek-flash)
        ▼
云数据库（player / player_life / narrate_history / llm_io）
```

**关键设计决策（勿擅改）**
- D001：AI 输出 = 纯文本 + 「」+ []，不是 JSON（内部解析器容错）
- D002：纯对话流，无事件引擎
- D008：`month_delta` 由 AI 决定（0~60），worker 不再默认 +1
- D010：墓志铭由 `ai_write_death` 独立生成
- D094-async：AI₁/AI₂ 两次独立调用，前端分两次调 worker
- D095：死亡判定三条 = AI₂ 剧情判死 → 寿限（age ≥ lifespan）→ 社会性（8 属性归零，<15 岁豁免）
- 状态变化协议（增量语义）见 `docs/state-flow.md` 第三节

**LLM 备注**
- 端点 `https://api.deepseek.com`，model `deepseek-flash`，环境变量 `DS_API_KEY`
- **必须显式传 `thinking:{type:'disabled'}`**（否则带思考链，慢且贵）
- ⛔ 长上下文下 `response_format: json_object` 会返回空 content → 已停用，走 options 兜底

## 7. 踩过的坑（省未来的时间）

1. **`SCORE_MAX_TOKENS` 是死代码**，实际吃 1500 → 长评分会被截断（P-194 的 0.7% 残差来源）。
2. **Canvas 量中文必须挂 CJK 垫片**：本机 `@napi-rs/canvas` 的 `measureText('汉')` = 0.6em，真机 = 1.0em → 不挂垫片几何探针全错（`node -r ./scripts/probes/_cjk_shim.js`）。
3. **判定「条件渲染 + 写 bounds」必须每帧先清空**，否则隐形热区（已中招 3 次：`_bounds` / `_listBounds` / `_freeInputBtn`）。
4. **微信小游戏上传用 `compileType: 'miniGame'`**；触摸坐标用 `clientX/clientY`，DPR 缩放会破坏命中检测。
5. **云函数写 llm_io 必须复用原 request_id**，否则 update 匹配 0 条 → 记录静默丢失。
6. **住建委/YHS 类站点与本项目无关**，但本机网络对 GitHub 偶发 443 抽风，push 失败隔 1~2 小时重试。
