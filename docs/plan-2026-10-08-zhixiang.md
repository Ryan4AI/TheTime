## 0. 一句话
把「身份卡 + 追榜单」的开局，换成「**序章开局 + 志向驱动 + 终局封号**」；
属性沉后台，榜单转终局，死神（凶险引擎）保留。

## 1. 流程（改动）
```
现在：穿越动画 → 身份卡(宣纸+雷达) → 正片(顶栏挂着榜单目标条)
改成：穿越动画 → 序章(开篇叙事 + 3选项=志向) → 正片(顶栏挂着"志向"入口)
终局：死亡 → 盖棺定论页(封号 + 墓志铭 + 人生志回顾)
```

## 2. 数据（改 `player_life.story`，不动表结构）⚠️需确认
story 现有：`arc / question / threads / npcs`。
新增：
```
goal        string   志向（一句话）
goal_step   string   现状（一句人话）
milestones  array    [{year:number, text:string}] ≤8 条
```
- 不新增表、不改 schema、不改校验函数（player_save 校验对额外字段放行）。

## 3. AI₁ prompt 改动（逐字）
### 3.1 新增「# 序章」段（**仅当 history 为空**时注入，替代普通叙事指令）
```
# 序章（本回合专用：玩家刚穿越而来）
这是这一世的【开篇】，不是普通一幕。写一段白话开篇（300~500字），把下面几点【自然揉进故事】，不要像填表：
- 你是谁（姓名）、多大、什么出身/职业、什么阶层；
- 现在是什么朝代、什么年月、在什么地方；
- 眼下什么世道（时局），你正处在什么处境里；
- 结尾把【你面前的三条路】摆出来——这是三个"志向"（你这一世想干成的事），作为 3 个选项。
志向要求：符合你的出身/年代、够得着（一世内可能实现）、三者各不相同。
输出 JSON：{content, options:["志向一","志向二","志向三"]}
（注意：本回合的 options 是"志向"，不是普通行动选项。）
```

### 3.2 新增「# 这一世的志向」段（正片每轮注入，放在"故事主线卡"之后）
```
# 这一世的志向
- 志向：{goal}
- 现状：{goal_step}
- 已成的印记：{milestones}
【要求】每一幕都要挂在志向上，三选一：推进——离志向近一步；设障——给志向添堵；岔路——递一条偏离志向的路。不许写与志向无关的纯日常。幕尾钩子要让人感到"这对我的志向意味着什么"。
```

### 3.3 「# 节奏（一幕制）」—— 保留（今晚已改）
### 3.4 「# 历史名人榜」段 —— 改写（见 §7）
### 3.5 字数（D004 锁定段，⚠️需拍板）
- 写作风格 `剧情文本200字左右` / 输出格式 `150~400字` → 建议 `300~500字`。

## 4. AI₂ prompt 改动（逐字）
在现有 `## F. story` 里追加三项：
```
- goal：这一世的志向（首轮后照抄，不变）
- goal_step：一句人话"离志向还有多远"（如"本钱攒到一半，铺面没着落"）
- milestones：值得记进"人生"的节点，≤8 条 [{year:数字, text:≤20字}]；只在【本幕确实达成一件可记之事】时追加（可好可坏：开张 / 中举 / 背上债 / 欠人情）；没有就不加。
```
另：**序章那一轮不做属性结算**（跳过 AI₂）。

## 5. worker 逻辑
1. `history 为空` → 走序章 prompt（§3.1）；本回合不跑 AI₂。
2. 新增常量 `SCENE_TYPE_WEIGHTS = [{推进:45},{设障:35},{岔路:20}]` → `weightedRandom` 选型 →
   注入 system 消息：
   ```
   【本轮这一幕：设障】给志向添堵（遇挫 / 被刁难 / 诱惑分心），本幕不要推进目标。
   ```
3. `buildSystemPrompt` 注入 §3.2 志向段。
4. `normalizeStory` 增字段：goal/goal_step ≤60 字；milestones ≤8 条、text ≤20 字。
5. `computeEraMeta`/榜单：顶栏不再输出"榜单接近度"（§3.4/§7）。

- 「盖棺定论」终局页（death 场景增强）：封号 + 名次 + 墓志铭 + 人生志回顾。
